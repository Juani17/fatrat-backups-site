FatRat Backups

FatRat Backups is a private, owner-operated integration for securely storing backup archives in the owner's Google Drive account.

The integration uses rclone and Google OAuth to transfer backup files between the owner's server and the owner's Drive. Backup files are intended to be encrypted before uploading. It is not a public service and does not offer registration or access to other users.

This website is informational only. It does not contain backup files, account credentials, or application source code.
